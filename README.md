# Employee Attrition Analysis | HR Dashboard


## 🔗 Live Project
GitHub Repository: https://github.com/kingofnisar-sudo/hr-attrition-analysis


## 📌 Project Overview
This project analyzes employee attrition using Python, SQL, and Power BI. The goal is to identify key factors influencing employee turnover and provide actionable insights.

---

## 🛠 Tools & Technologies
- Python (Pandas, NumPy)
- SQL (MySQL)
- Power BI
- Excel

---

## 📊 Project Workflow
1. Data Cleaning using Python (handled missing values, duplicates, data types)
2. Data Analysis using SQL (attrition rate, grouping, filtering)
3. Dashboard Creation using Power BI

---

## 📸 Dashboard Preview
![Dashboard](images/dashboard.png)

---

## 🔍 Key Insights
- Higher attrition observed in Marketing and Finance departments
- Medium salary category shows highest attrition
- Employees aged 18–25 show higher turnover
- Mid and Senior level employees show higher attrition trends
